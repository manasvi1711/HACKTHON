# Lumora Workspace Release Notes v3

## Upload improvements

Version 3 allows individual file uploads up to 50 MB. Uploads now resume automatically after a dropped network connection.

## Activity timeline

A new activity timeline shows who viewed, edited or shared each file during the last 90 days.

## Removed features

The legacy desktop sync client from version 1 is no longer supported. Use the current sync client instead.
