# Lumora Workspace Product Manual

## Uploading files

Version 2 allows individual file uploads up to 20 MB. Larger files are rejected with an "upload too large" message.

To upload a file:

1. Open the workspace where the file should be stored.
2. Select **Upload** in the toolbar.
3. Choose one or more files from your computer.
4. Wait until each file shows the status **Uploaded**.

## Supported file types

Workspaces accept documents, spreadsheets, presentations, images and PDF files. Executable files are blocked.

## Sharing a workspace

Workspace owners can invite colleagues by email from **Settings > Members**. Invited members receive the Viewer role until an owner changes it.

## Storage quota

Each workspace on the Business plan includes 1 TB of shared storage.
